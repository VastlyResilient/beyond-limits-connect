# Beyond Limits Connect

A demonstration family-engagement system built for the **Beyond Limits Academic Program**
(a program of the Stamford Peace Youth Foundation, Stamford CT) — a hyper-personalised
alternative to ParentSquare for a program that is not part of a school district.

- `index.html` — the program site: platform, participant-code engine, attendance recovery, Remind → ParentSquare migration
- `studio.html` — the staff console (family records, review queue, messaging, attendance, onboarding, agreements, calendar, directory, tutors, ParentSquare sync, insights, settings)
- `family.html` — what a family sees: no app, no password, auto-translated

Contains **sample data** for demonstration. Not affiliated with ParentSquare. The Beyond Limits
logo is the program's own artwork.
